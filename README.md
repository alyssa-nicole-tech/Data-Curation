#📚 Overview

This repository is for collecting insights on socio-cultural nuance performance improvement by transformer models using Data Linguistic and Natural Language Processing Techniques:

Ambiguity in social-cultural language exchanges often results in a message receiver misinterpreting meaning from a message deliverer. This paper explores whether it is possible to highlight socio-cultural nuance for message recipients using a combination of quantitative, qualitative, and computational linguistics techniques. Given a corpus of multimodal data, the study decodes the underlying elements of the speaker’s expressions using inspiration and frameworks from previous studies. The study begins with a review of previous research on approaches to analyzing syntax, morphology, lexicon, semantics, sociolinguistics, and phonology. It continues to establish language as a social and cultural tool through a review of key sociolinguistic findings from anthropological studies. The literature is applied to comprise a guiding framework for classical techniques. Next, the study implements classical approaches for language analysis within a Python environment to identify socio-cultural linguistic nuances. The dataset selected for this study is a body of video clips from the series, “The Daily Show with Trevor Noah” produced between 2015 and 2021. The data has been transformed from it’s original multi-media format into a text-only format for the purposes of using corpus linguistics techniques. The data is analyzed to produce insight on patterns of linguistic vehiculation of nuanced signals for meaning, sentiment, semiotics, and stylistics. The patterns abstracted are used as annotation markers for a second set of randomized satire linguistic data. The labels are used for language model training and evaluated against baseline performance for increases in socio-cultural nuance detection.
