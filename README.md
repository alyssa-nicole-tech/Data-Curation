# Dataset curation for improved Transformer performance on sociologically complex language patterns
This repository is for storing urls of Raw Media Sources that contribute to the goal of improved Transformer  performance for sociologically complex language patterns: satire, irony, nuance, professionalism, vagueness-ambiguity, sarcasm & mixed sentiment
READ ME files for the URL list house descriptions and explanations of examplified methodology from linguistics and cognitive science research on sociologically complex human language patterns 
Datasets can be used by semantic technologies, NLP, statistical modeling, heuristic evaluations and training pipelines targeting aquisition of performance metrics on socially complex language patterns
