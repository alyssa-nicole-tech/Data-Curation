#📚 Overview

This repository is for collecting insights on socio-cultural nuance performance improvement by transformer models using Data Linguistic and Natural Language Processing Techniques:

#📚 Methods

  A. DATA CURATION  ---Raw media sources are identified in web domains, databases, or published datasets

  B. DATA INGESTION ---Raw media files are extracted and saved in cloud storage warehouses

  C. DATA CLEANING  ---Warehouse files are cleaned & re-structured in Python / SQL Environments 
  
  D. DATA LABELING  ---Datasets are labeled for LLM training
